# Pet Match

O Pet Match é uma aplicação web para divulgação e adoção de animais.

## Objetivo

A plataforma conecta pessoas interessadas em adotar animais a doadores que desejam disponibilizá-los para adoção.

## Tecnologias

- React
- JSX
- JavaScript
- CSS
- Node.js
- Express
- MariaDB
